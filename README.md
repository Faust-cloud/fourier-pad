# 傅里叶画板

**画任意一笔，看一组旋转的圆把它重新画出来。**

👉 在线玩：https://faust-cloud.github.io/fourier-pad/

---

## 这是什么

你在屏幕上随手画一条线，它会做三件事：

1. 把这条线**沿弧长重采样**成 256 个点；
2. 对这两百多个复数做一次**离散傅里叶变换**；
3. 用放大率最高的若干个「旋转的圆」首尾相接，把原线重新画一遍。

谐波（圆）越多，画得越像。右下角的**误差**数字就是这个逼近的均方根误差 —— 拖动「圆」的滑块，能直接看到误差怎么下降。

## 能玩什么

| 操作 | 说明 |
|---|---|
| **自己画** | 在画布上按住拖动，松手即算 |
| **预设** | 方波 / 三角 / 五角星 / 心形 / 无穷符号，一键加载 |
| **圆** | 40 → 120，看精度怎么上升（也看方波的角为什么永远画不圆） |
| **速度** | 0.15× 慢放，可以看清每个圆各自转多快 |
| **显示圆 / 重播** | 关掉圆只看结果，或者从头再画一遍 |

右上角那张小图是**幅度谱**：越靠左的谐波振幅越大。方波的谱衰减得慢（1/k），所以它需要很多圆才像；圆的谱只有一根柱，一个圆就够了。

## 一点原理

对采样点 $z_n = x_n + i\,y_n$（$n = 0,\dots,N-1$），系数是

$$c_k = \frac{1}{N}\sum_{n=0}^{N-1} z_n\, e^{-2\pi i k n / N}$$

重建时把前 $M$ 个最大的 $c_k$ 依次接起来：

$$z(t) \approx \sum_{k \in S} c_k\, e^{2\pi i k t}$$

每一项 $c_k e^{2\pi i k t}$ 就是一个半径 $|c_k|$、角速度 $k$ 的圆。所以动画里那一圈套一圈的东西，不是装饰，**就是傅里叶级数本身**。

## 技术

- **单个 HTML 文件**，0 依赖、0 构建、0 后端
- DFT 用最朴素的 $O(N^2)$ 实现，$N=256$ 时约 6.5 万次乘加，一次几毫秒，不值得上 FFT
- 采样按**弧长**等距而非按下笔时间等距 —— 否则画快画慢会扭曲频谱
- Canvas 2D + `pointer` 事件，鼠标与手指同一套代码
- 带 Service Worker，装到桌面后**断网也能打开**

## 本地运行

```bash
git clone https://github.com/Faust-cloud/fourier-pad.git
cd fourier-pad
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也能用，只是离线缓存不会生效（`file://` 下 Service Worker 不注册）。
